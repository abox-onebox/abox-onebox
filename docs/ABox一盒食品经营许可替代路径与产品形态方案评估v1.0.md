# ABox 一盒 · 食品经营许可替代路径与产品形态方案评估 v1.0

> 结论文件 · 2026-09-22
> 触发问题：「除了小程序和 H5，有没有其它的解决方案？因为食品经营许可证是一个坎儿。」
> 前置口径：当前生效裁定 = **单主体自营 + 半成品供应链**（`.workbuddy/memory/ref/资质与合规.md` §一）。

## 一、先纠正一个前提

**《食品经营许可证》不是"渠道门槛"，是《食品安全法》第三十五条的法定准入。**

> 从事食品生产、食品销售、餐饮服务，应当依法取得许可。

它约束的是「**谁在制作并销售餐食**」这个事实，与「用什么渠道卖」完全无关。
换小程序 / H5 / APP / 微信群 / 电话订餐 / 美团 —— **对许可证这件事，效果是零。**

### 而且真正拦住你的，其实不是许可证

| | 实际情况 |
| --- | --- |
| 许可证本身 | 免费、含现场核查约 **10 个工作日**（北京）—— 不是瓶颈 |
| **真正卡人的** | 它要求的**【实体加工场所】**：要能过现场核查、要挂 ABox 门头、要满足"证照地址＝线上地址＝出餐地址" |

⇒ 所以「绕过许可证」这个提法要改一下：**你要绕开的其实是"自有实体场所"这个前提。**
而这件事，**只有两条路能解决**：

- **路径一：换产品形态** —— 让产品不再是"现制即时食用的餐饮服务"
- **路径二：换持证主体** —— 让别人持证经营，你做品牌与运营

## 二、决定性的分界线：123 号令 vs 124 号令

2026 年市场监管总局连出三部规章，把线上食品经营切成三个业态、各配一部规章：

| 规章 | 业态 | 施行日期 |
| --- | --- | --- |
| **120 号令** | 直播食品销售（直播间 / 主播 / MCN） | 2026 年 |
| **123 号令** | **网络餐饮服务**（外卖后厨加工与配送）；同时废止 2017 年 36 号令 | **2026-06-01** |
| **124 号令** | **网络食品销售**（线上预包装食品店铺）；明确**「不涉及现制加工」** | **2026-05-20** |

### 两部的界分（这是整份文件的钥匙）

| | 123 号令 · 网络餐饮服务 | 124 号令 · 网络食品销售 |
| --- | --- | --- |
| **定义** | 网上点「外卖或**现做的饭菜**」，现做、现卖、现送，**即时食用** | 线上购买「**预包装 / 散装食品**」，成品**可以放一段时间** |
| **行业释义明示** | **明确把「盒饭」「简餐」列举在这一侧**（与奶茶、咖啡、炒菜并列） | 含**预制菜**、零食、牛奶等 |
| **入网者门槛** | 实体经营（§22：**须有实体门店**，经营地址与许可证一致） | 许可**或仅销售预包装食品备案**（§18） |
| **公示** | 网店名＝招牌名、主页持续展示资质＋**实体门店照片**＋实际经营地址、无堂食标识（§11–13） | 主页公示许可/备案信息；食品主页展示**预包装标签信息**（§20） |
| **加工** | §26/27：不得在加工区外加工；**不得委托其他经营者加工**；封口后不可复原 | 不涉及现制加工 |
| **贮存运输** | §28/29：配送人员培训记录；特殊温度要求须采取措施 | §22：有温湿度要求须符合条件 |
| **罚则** | 虚假资质 1–20 万；**双罚**（对个人处年收入 1–10 倍） | 虚假资质 1–20 万；未公示拒不改正 5000–3 万；**双罚**（§40） |

⚠️ **请特别注意 123 号令 §26/§27 的那一句**：「**不得委托其他经营者加工**」。
这条以法条形式关闭了「4 家供应商代工出餐 + ABox 贴牌」的形态 —— 只要定性在网络餐饮服务。
**若同时使用虚假资质，可处 1–20 万罚款，并可对法定代表人、主要负责人处上一年度收入 1–10 倍罚款。**

## 三、关键事实：备案可以替代许可（但有严格边界）

**《食品经营许可和备案管理办法》（总局令第 78 号，2023-12-01 施行）把「仅销售预包装食品」由许可制改为备案制。**

| 项 | 内容 |
| --- | --- |
| 依据 | 同上；《食品安全法》第三十五条（仅销售预包装食品报县级市场监管部门备案） |
| 时限 | **北京市办事指南（昌平区）**：受理 1 个工作日 + 决定 1 个工作日，制证 0 + 发证 0 ⇒ **约 2 个工作日** |
| 有效期 | 与营业执照一致 |
| 材料 | 备案信息采集表 + 营业执照（可网上核验的免提交）+ 设备设施/经营布局清单 + 食安制度目录清单 |
| 办理 | 全流程网上办理，支持电子签章 |

⚠️ **两条硬边界（很容易被误读成"万能"）**

1. **备案只覆盖「仅销售预包装食品」**。一旦增加需许可的经营项目（**如餐饮服务**），
   **必须重新申请食品经营许可证，原备案自动失效** —— 备案不能"顺手把餐饮也做了"。
2. **「已取得食品生产许可的企业销售自产预包装食品，无需另行备案」** —— 反过来说，
   委托他人生产的品牌方**必须自己完成备案**（见 §五）。

## 五、方案 B 详解（唯一"既快、又保持自主"的路）

### 5.1 结构

```
食品生产企业（持 SC 食品生产许可证） ── 受托生产 ──▶ 预包装餐食
                    ▲
                    │ 委托生产合同（10 个工作日内双向报告）
                    │
ABox 一盒（完成「仅销售预包装食品备案」）── 品牌 + 销售 ──▶ 用户
```

### 5.2 ⭐ 法理依据是明确的 —— 而且是监管**主动预设**的

**《食品委托生产监督管理办法》（总局令第 113 号，2026-12-01 施行）** 明确规定：

- **委托方（品牌方）**：「依法取得食品生产经营许可 **或进行仅销售预包装食品备案**，具备监督受托方……的能力」
- **受托方**：必须依法取得**食品生产许可**，许可证副本载明的**食品类别和品种明细应当包括受托生产的食品**
- 覆盖范围明确包含：**商标许可、特许经营、贴牌生产、来料加工、委托运营** ——
  「只要是你『出品牌、出标准，别人代加工生产』的食品，都属于新规监管范畴」

⇒ 也就是说：**"品牌方只做备案、由 SC 工厂生产"这种结构是法规明确承认的合法形态**，不是打擦边球。

### 5.3 好处

| 好处 | 说明 |
| --- | --- |
| 准入时间 | 从「周/月级」降到「**天级**」（备案 2 个工作日 + 找到工厂） |
| 无实体门店要求 | 123 号令的实体门店、三地址一致、门头一致、无堂食标识**全部不适用** |
| 无 EDI / 无平台备案 | 自营形态不变 |
| ⭐ 战略自洽 | **对标玉子屋本来就是工厂化生产 + 集中保温配送**，不是门店现炒。这条路与你们的战略方向一致 |

### 5.4 代价：113 号令把责任压到「委托方」

| 义务 | 内容 |
| --- | --- |
| 资质 | 委托方须有许可或备案且在有效期内；受托方须 SC 且范围覆盖 |
| 人员 | 配食品安全管理人员；制定《食品安全总监职责》《食品安全员守则》 |
| 机制 | 建立《食品安全风险管控清单》，落实「**日管控、周排查、月调度**」，全过程记录存档 |
| 监督 | 定期评估受托方生产能力与生产过程；配专职/兼职监督人员；建**受托方监督台账**；成品抽样检验、标识审核 |
| **报告** | 合同**订立 / 变更 / 终止后 10 个工作日内**，双方**分别向各自所在地县级市场监管部门**报告 |
| **标签** | 预包装标签须**同时标注委托方与受托方**名称、地址，分别冠以「委托方 / 受托方」字样 |
| 核查 | 每半年核验双方资质有效性与许可范围匹配度 |
| ⛔ 禁止 | **「需要完整工艺生产的食品，不得将部分环节委托生产」**；不得通过合同减轻或免除法定责任 |

### 5.5 ⚠️ 三个必须提前想清的问题

1. **产品能不能真做成"可存放"？**（最关键）
   124 号令明示「不涉及现制加工」；123 号令把「现做、现卖、现送、**即时食用**」划在餐饮服务侧，
   且行业释义**明确列举了「盒饭」**。
   ⇒ **如果盒饭仍是"当日做、当日送、当日吃"、没有保质期标签，监管会穿透认定回 123 号令 → 许可证依然是硬要求。**
   要让 B 真正成立，产品必须真实具备：**密封包装 + 完整标签 + 明确保质期与贮存条件 + 出厂检验**。
2. **SC 类别能不能覆盖？** 必须由受托工厂确认其**食品生产许可证副本载明的类别与品种明细**能否覆盖该产品。
   具体归入哪一类由当地许可分类目录决定，**不能自行推断** —— 这件事只有工厂能答。
3. **写字楼里的复热环节** 若预包装餐食需要复热，用户的复热条件（微波炉到位率）、
   复热后的卫生责任归属，都要重新设计。

## 六、方案 C 详解（唯一"完全不办证"的路，但不建议做主线）

成立条件（**三个都不能破**）：

1. **证照主体 = 合作门店**，且小程序/收款主体**也是门店**（用户货款进**门店**的商户号）
2. ABox 只收**品牌使用费 / 运营服务费**，**不碰用户货款**
3. 产品在**门店场所内**制作（满足三地址一致）

⚠️ **一旦用户货款进 ABox 账户** → ABox 即成为实际经营者 → **无证经营餐饮服务**（且叠加二清风险）。

⚠️ **代价**：用户、复购数据、品牌资产都在合作方主体下 —— ABox 从「生意主体」降为「服务商」。
可用作**冷启动过渡**，**不宜作为长期主线**。

## 七、建议的决策顺序

1. ⭐ **先做「产品形态决策」，而不是「办证决策」。**
   决定你们卖的是「**现做热食盒饭**」还是「**可存放的预包装餐食**」——
   这一个决定改变后面所有事（监管归属、要不要场所、要不要许可证、产品体验、成本结构）。
2. ⭐ **最快的合规验证方式不是问部门，而是找已经合规在做这件事的工厂。**
   找 2–3 家做**冷链盒饭 / 预制餐食**的 SC 工厂谈代工 ——
   他们的**产品归类、许可类别、标签方案、保质期设定**都是现成的，
   比自行推断可靠得多，且谈一次就能把方案 B 的三个未知数同时问清。
3. **可以并行启动的**（不论最终走哪条路都要）：ICP 备案 · 小程序账号与企业认证 · 微信支付商户号。
4. **不要做的事**：
   - ❌ 不要用挂靠 / 借证（路径 E）—— 双重违规。
   - ❌ 不要在产品还没真正变成预包装时，就以"预包装"名义上线 —— 有**穿透认定**风险，
     且触发 124 号令**虚假备案罚则 1–20 万**。
