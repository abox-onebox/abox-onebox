v1.0 · 2026-09-14 · 源自原型 v4.9.1 实际 :root

一、总则

本规范是 ABox 一盒视觉的唯一事实来源。开发期所有颜色、字号、间距、圆角、阴影、动效，一律引用本规范的 token，不得在页面里写裸值。

适用范围小程序（用户端 + 团长端）、供应商 Web、运营后台 Web
风格定位高端极简 · 少文字 · 多留白
取值来源原型 prototype/index.html 的 :root（v4.9.1「视觉规范精修版」）
派生产物apps/miniprogram/src/styles/tokens.scss · apps/admin-web/src/styles/element-override.scss · packages/shared-utils/tokens.json（图表 / Canvas 用 RGB）
⚠️ 两套色值不要混用：本规范（产品 UI）取原型 :root 的实际值；而《审查报告》《交接包》等文档型 HTML 使用自己的一套排版变量（如 #FBF7EF / #EDE3D0 / #A08A6A），仅用于纸张打印观感，不进入产品代码。

八、楷体真机降级方案

小程序不支持自定义字体文件（无法通过 CSS @font-face 稳定加载），需按以下优先级降级：

  1. 首选：wx.loadFontFace() 动态加载网络版楷体 —— woff2 托管在腾讯云 COS（≤2MB），首次加载后本地缓存。
  2. 失败降级：走系统字体链 —— iOS 自带「Kaiti SC」可用；安卓多数机型无楷体 → 降级到 serif（宋体系），此时标题字重加大以弥补气质差。
  3. 关键数字兜底：价格 / 金额等对观感最敏感的字符，建议用图片或 SVG 徽标兜底，避免双端观感分裂。
  4. 后台无限制：Element Plus 端直接 font-family: var(--font-kai) 生效，无需降级。
