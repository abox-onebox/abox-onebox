## 七、同步方式

```bash
pnpm docs:sync          # 从工作区根目录同步 ABox一盒*.md / *.html 到本目录
```

同步规则（见 `scripts/sync-docs.mjs`）：

1. 只同步文件名以 `ABox一盒` 开头、扩展名为 `.md` / `.html` 的文件；
2. **同 base + 同扩展名的多版本，只保留最高版本**（按数值段比较，v1.10 > v1.9）；
   被淘汰的文件会在终端打印，不会静默丢弃。扩展名不同视为两份产物（如 `xxxv1.3.html` 与 `xxxv1.3.md` 都保留）。

> 当前实际：同步 **23** 份，自动跳过 4 份旧版本
> （`业务运作理解v1.0` · `数据库ER设计v1.0` · `项目目录结构v1.0` · `MVP优化交接包v1.0`）。

## 八、变更流程

1. 在**工作区根目录**改文档（注明版本与变更行），本目录不要手改
2. 执行 `pnpm docs:sync` 同步
3. 提交 `docs: ...`
4. 再改代码，PR 中引用文档章节号
