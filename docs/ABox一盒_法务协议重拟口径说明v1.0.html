〇、请先确认这一句（最重要）

ABox 一盒是「预包装食品销售商」，不是「餐饮服务提供者」。

六、⚠️ 头号风险：「一盒」组合装只能走「情形 1」

产品名为「一盒」，本质是多件独立预包装商品的组合包装。监管口径下「组合/二次打包」对应四种性质完全不同的行为，只有第一种合法：

#实际动作法律定性是否需要 SC结论
1各单品原封不动装入组合盒/袋（不拆封、不加热、不改标签）简单物理组装，不属食品生产活动否✅ 成立
2拆开原包装，分装成小份 / 装盘分装 = 食品生产行为是❌ 不成立
3拆封后加热 / 摆盘 / 调味 / 复配再装盒热食类食品制售（餐饮服务）需餐饮许可 + 实体门店❌ 不成立
4改标保质期 / 将可单独销售单品改为不可单独销售涉及生产性质操作是❌ 不成立

情形 1 必须同时守住的六条红线

  1. 保持内含食品原有状态 —— 独立包装仍可单独销售
  2. 不拆分、不破坏原包装、不分装
  3. 不改变原包装标签信息
  4. 不加热、不调味、不复配、不混合
  5. 组合过程环境清洁、杜绝交叉污染
  6. 履行进货查验、索证索票、进货台账，并对组合包装产品承担全部法律责任
⭐ 合法空间：2023 年已有地市（淮安）将「组合包装食品」列为可申请生产许可的类别（其他食品，类别编号 3101），定义为「多种原料分别形成独立包装，组合形成预包装食品」。 只要每个单品都是独立预包装，「组合成一份」本身完全合法且有先例。

⚠️ 备案失效条款（请务必在协议中设防）

78 号令第五条第二款：仅销售预包装食品的经营者在备案后增加其他应当取得食品经营许可的项目的，取得许可之日起备案自行失效。 78 号令第四条末句：除仅销售预包装食品外，还开展其他食品经营项目的，应当依法取得食品经营许可。

⇒ 一旦操作越出「仅销售」这条线，备案自动失效 —— 不是「补一下」的问题，而是整条路线坍塌。

七、各协议必写条款

7.1 用户协议

  1. 服务性质：预包装食品的预订与销售，明确「非现场制售、非餐饮服务」。
  2. 商品来源与资质：由具备食品生产/经营资质的品牌方供应，平台负责资质核验并持续公示。
  3. 下单与截单：T-1 24:00 截单，以小程序实时展示为准。
  4. 交付：由该办公楼团长送至用户工位，约 11:30，以页面展示为准。
  5. 价格与支付：微信支付，价格以下单页展示为准。
  6. 售后与退款：请法务明确 —— 预包装食品是否适用七日无理由退货，以及破损 / 漏发 / 错发的处理口径。
  7. 食安责任：属生产方责任的由生产方承担；平台承担销售者责任及先行赔付安排（如有）。

7.2 隐私政策

  1. 收集范围：手机号、微信 OpenID、收货楼宇 / 工位、订单与支付信息。
  2. 团长额外收集：身份信息（用于灵活用工平台代发佣金、代扣代缴个税）。
  3. 使用目的、存储期限、第三方共享（微信支付、灵活用工平台、配送环节）。
  4. 用户权利：查阅、更正、删除、注销。

7.3 团长合作协议

  1. 合作性质：平等主体的推广服务合作关系，明确不构成劳动、劳务、雇佣或代理关系。
  2. 身份叠加：团长同时是平台普通用户，使用同一小程序账号。
  3. 佣金：按单计佣，费率分档 —— 见习 8% / 正式 9% / 金牌 10% / 首席 12%。
  4. ⭐ 佣金基数（现行 v1.0 写错，须修正）：系统按「实际交付（实发）份数 × 商品单价」计算（剔除退款），不是「订单实付金额」。
  5. 反传销红线：不按发展下级团长数量计酬、不按下级销售业绩抽成，不构成团队计酬 / 拉人头。
  6. 团长义务：楼内推广、末端交付至工位、配合售后与质量反馈。
  7. 结算与提现：订单于交付日 14:00 确认后生成待结算佣金，次日 02:00 自动入账；提现经灵活用工平台代发并代扣代缴个税。

十、待法务确认 / 出具意见的事项

#问题为什么关键
①「一盒」组合装在本项目实际操作下，是否稳定落入情形 1（原封不动组装）？只有情形 1 合法；落入 2/3/4 整条预包装路线不成立
②合作生产方须持 SC（食品生产许可）还是食品经营许可即可？持餐饮许可的主体生产的食品不是预包装食品，属超范围经营
③预包装食品是否适用七日无理由退货？不适用时下单页与协议如何提示？直接决定售后条款与页面提示
④团长末端交付环节的破损 / 延误责任如何划分？团长非员工，责任边界需明确
⑤灵活用工平台代发代扣个税的三方法律关系如何表述？平台是否为扣缴义务人？影响团长协议税务条款
⑥组合包装产品是否需单独申请组合包装食品生产许可（类别编号 3101）？各地口径不一，需确认北京是否可参照

十一、三条红线（协议不得突破）

  1. 资质混用 —— 不得约定任何加热、拆包分装、调味复配、改保质期的行为。一旦从「销售」滑入「制售」，需《食品经营许可证》，且备案自动失效。
  2. 不得隐藏类目 —— 微信要求类目与实际功能一致；124 号令要求店铺主页显著位置持续公示资质（常驻功能，非提审时贴一次）。
  3. 单品逐一确认 —— 酒类（部分地区预包装备案不含酒）、进口商品（须中文标签 + 入境检验检疫证明）须逐品单独确认后上架。
