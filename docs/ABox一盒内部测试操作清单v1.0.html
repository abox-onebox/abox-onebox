身份要一人一个，别共用
  • 同一个身份在同一天只能下一单（这是设计，不是故障）。两人共用 dev:1001，第二个人一定会被拦，然后被写成 bug。
  • 多人同时测：A 用 dev:1001（李明·首席 12%）· B 用 dev:1002（王芳·金牌 10%）· C 用 dev:1003（张磊·正式 9%）· D 用 dev:1004（赵静·正式 9%）· E 用 dev:1005（陈强·见习 8%）。
  • 如果你被提示「已提交过该日出餐的订单」——先确认是不是别人用了你的身份，再决定要不要记。
✅ 库里已经预置了一批「模拟数据」—— 页面打开就有东西，不用你自己造
  • 一共 34 张订单，覆盖全部 11 种订单状态（含「待支付」「已支付未截单」「已出餐」「配送中」「已送达」等中间态）；退款单有待审批 / 已通过 / 已退款 / 已驳回四种；提现单五种状态齐全；配送单有「待推进 → 已叫车 → 已发车 → 已送达」完整四态。后台的看板、订单、财务、配送各页打开就有数据可判。
  • ⚠️ 这些模拟订单属于另一批专用账号（昵称以「演示·」开头），不是你的身份 —— 你在用户端「我的订单」里看不到它们，那是正常的；后台各页能看到。
  • 模拟数据分布在过去 9 天一直到今天。之所以补「今天」这一天的数据，是因为佣金明细、打包任务、看板「今日」档、配送单这几页默认就看今天 —— 只补历史日期的话，打开是空表，容易被误记成缺陷。
  • ⭐ 由此可得一条预期行为：佣金页今天显示的是「待入账」而不是「已结算」。因为佣金是「出餐当天记账、次日 02:00 才入账」——今天完成的单本来就还没入账。这是设计，不是缺陷。
  • ⚠️ 对账页（财务 → 对账）默认看今天，但它算的是支付日（不是出餐日），而模拟数据的支付日都在过去 → 默认是空的，这是预期的。把日期改成某个出餐日的前一天（支付日 = 出餐日 − 1）就能看到数据。
  • ⚠️ 供应商结算页默认看今天，而采购款按口径次日 02:00 才生成 → 今天为空是正常的，往前看一天才有数。
  • ❗ 模拟订单全部落在今天及更早，没有占用「明日」 —— 所以你自己下单（U6）不会被挡。若被提示「已提交过该日出餐的订单」，先看上面那条「身份要一人一个」。
✅ 先看这里：上一版说「出餐 → 送达还没接上」，2026-09-18 起已经接上了
  • 订单现在会跟着履约走。供应商确认出餐 → 订单变「已出餐」；后台把配送单推进到「已发车」→ 订单变「配送中」；再推进到「已送达」→ 订单变「已送达」，此后才会自动确认收货、才会产生佣金。上一版清单里那 5 个「⚠ 已知未完成」小标签已全部撤掉。
  • ⚠️ 但要看到佣金（U12 / U13 / A13 / A15），必须先把这条链走完，而且链上有顺序：先供应商端确认出餐（供应商那份清单的步骤），再回后台订单 → 配送把配送单一步步推进到「已送达」。跳着点不行 —— 页面上的「推进到 X」只会给下一步，接口也会拒掉跳级。
  • ⏳ 还有时间前提：佣金先记成「待入账」，要等出餐日次日 02:00 的入账跑批才进余额（后台「财务 → 佣金」页有补跑入账按钮，可以让工程帮你补，不用真的等）。当天就要求余额到账，不是缺陷。
  • ❗ 真正该记的错：出餐确认之后订单仍停在「已截单」、或推送到「已送达」之后订单仍是「配送中」 —— 这两条正是这个批次要保证的，请按 P1（结果不对） 记，写明「履约推进后订单未跟上」。
  • 其余步骤（下单 / 支付 / 取消 / 退款 / 后台各页 / 时刻表）与上一版一致，不受影响。

五故意做错的三件事（最能试出问题）

编号 故意怎么做 必须出现的结果 谁做
N1 一天之内，同一个身份下两次单 第二次必须被拦，并说清「哪个出餐日已经下过」；放过去才是 bug 用户端测试人
N2 两个窗口同时改同一张配送单 后提交的那次必须提示冲突并要求刷新；静默覆盖掉别人的填写才是 bug 后台测试人
N3 提现时填一个大于可用余额的金额 应被拒绝并说明原因（余额不足 / 冻结额不足），不应「提交成功」后没有下文 用户端测试人

另外两条更有杀伤力的越权用例（换低权限账号去访问资金接口、服务端数据收窄）由工程用接口直接验， 不在本清单内 —— 让业务测试人手工点，反而测不准。

八三条须知（记住就不会误报）

  • 支付是「自动成功」的模拟通道。 看到「已支付」不等于钱到了 —— 别拿它当财务依据，也别惊讶它为什么不用输密码。
  • 系统内部的时间被拨快过。 为了让「任何时间都能下单」，环境把北京小时平移到了 20:00。所以不要拿这个环境验真实时间行为（要按真实时间跑，让工程加 --clock=off 重起）。
  • 数据随手改没关系，但别当权威。 这个环境里的数据是试验场；权威永远是种子脚本与正式库。测完想还原，加 --seed 重起即可。
