### 交付物
- 团长端 P11–P20 全部可点击
- `ab_leader_invite` 表落库，晋级审计可查
- 单测：代退申请**不改订单金额、不触发退款**；佣金按实发份数计算

### 验收标准
1. 用户在"我的"可申请团长，**勾选协议后立即生效**，tabBar 出现团长入口（无审核流程）
2. 团长对本楼订单发起代退申请后：`ab_refund.status='applying'`，订单进入 `refund_applying`，**资金未动**
3. 一键分发后佣金按 `实发份数 × 等级费率` 计算，与余额流水一致
4. 提现申请可提交并进入待审批

### 风险
佣金基数口径（实发 vs 下单）—— 已定稿"按实发"，实现若用错会导致全站佣金偏差

- 8 个定时任务上线，可控触发（含手动补跑接口）
- 消息模板在后台可配置
- 单测：任务幂等（重复触发只生效一次）、反向结算金额、佣金入账金额

### 验收标准
1. 模拟 T-1 24:00 触发截单：未支付订单全部 `cancelled`，已支付转 `cut_off`，4 家供应商收到备料量

3. 每个任务重复触发 **不产生重复数据**
4. 退款结果**必推**订阅消息（用户可感知）
5. 供应商应付单生成后**不自动打款**，财务在后台登记回单号后状态转 `success`

### 验收标准
1. 一个办公楼完整跑通 **3 个自然日**（含一次完整跑批与一次退款）
2. 单份结算账实相符（等式闭合）：**协商供价（示例 ¥14.00）+ 场地费（默认 ¥0）+ 打包人工 + 配送费 + 佣金（按等级）+ 毛利（结果值）= ¥25.80**
3. 无 P0 缺陷；P1 缺陷 ≤ 3 且均有临时规避方案
4. 回滚演练成功（10 分钟内可回退上一个版本）
