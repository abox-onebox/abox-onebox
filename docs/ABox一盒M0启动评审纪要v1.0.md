## 三、本次评审确认的关键口径（开发期不得自行更改）

| # | 口径 | 权威来源 |
| --- | --- | --- |
| 1 | 套餐价格 **¥25.80 / 份**（一饭四菜 + 主食） | 交接包 L1 / C1 |
| 2 | 团长佣金 **4 级阶梯 8% / 9% / 10% / 12%**（见习 / 正式 / 金牌 / 首席） | 交接包 C2 |
| 3 | 分账校验式：供应商应付 **¥14.00** + 集散中心 **¥5.00**（米 ¥2 + 打包 ¥3）+ 团长佣金（按级，首席 ¥3.10）+ 平台毛利 **¥3.70** = **¥25.80** | 交接包 C9 |
| 4 | 团长**提交申请即生效**（勾选协议，CA 电子签入二期）；见习 30 天未促单失效 | 交接包 C3 |
| 5 | 集散中心**系统表驱动**，默认 4 个可增删，**不得硬编码** | 交接包 C4 |
| 6 | 截单后退款**三段式**：用户不可自助退 → 团长代退申请 → 后台审批后实际退款 | 交接包 C6 |
| 7 | 端数表述统一为「**4 角色 · 3 载体**」（小程序 / 供应商 Web / 运营后台 Web） | 交接包 C7 |
| 8 | 结算通道：供应商与集散中心 = **日结 + 人工对公**（系统只生成应付单 + 登记回单，不接支付通道）；团长佣金 = **系统自动结算 + 灵活用工平台代发代扣**（团长到手为税后金额） | 交接包 C10 / C11 |
| 9 | 时间轴：开团 T-1 14:00 · 截单 T-1 24:00 · 配送单 T 日 00:30 · 出餐 ≤ 09:30 · 自动确认 T 日 14:00 · 佣金与应付跑批 T+1 02:00 | PRD v2.1 / 状态机 v1.0 |
| 10 | 金额单位：数据库 `DECIMAL(12,2)`（元）↔ API **整数分**（`priceFen`），换算只允许出现在 DTO ↔ Entity 边界 | 表结构评审 P1-2 |
| 11 | 平台定性：**自营模式**（向供应商采购 + 以 ABox 品牌销售），不涉二清；合规焦点在**发票链条** | 合规清单 §6.2 |
| 12 | 主体：北京巡礼之年科技有限公司（品牌 ABox 一盒）；供应商名（三味屋 / 京味小馆 / 老李家 / 四季鲜蔬）均为**演示占位** | 交接包 C5 |

> **口径变更流程**：任何一条的改动必须走《协作规范 v1.0》§六 —— 提 PR + 更新《基线冻结清单》并升版，禁止口头变更或在代码里私改。
