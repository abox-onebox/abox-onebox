## 一、端上《隐私政策》新增三条款（已落真源，逐字如下）

以下三条已写入 `apps/miniprogram/src/constants/agreements.ts` 的 `PRIVACY_POLICY`
（版本 `1.0-draft`，`updatedAt` 2026-10-20），渲染页「我的 → 设置 → 隐私政策」直接展示：

### §一 我们收集哪些信息（新增条目）

> 页面访问记录（匿名）：你在小程序中各页面的访问路径与停留时长。此类记录不包含你的账号、设备标识、位置等任何身份信息，也无法与其他信息关联。

### §二 我们如何使用信息（新增条目）

> 上述页面访问记录仅用于聚合统计分析，例如了解各页面的使用频率与停留分布，以改进产品功能与使用体验；不用于向你进行个性化推荐。

### §四 信息的存储与保护（新增条目）

> 页面访问记录自收集之日起保留 180 天，到期后删除原始记录，仅保留不含具体路径的聚合统计结果。

✅ **「180 天」承诺已闭环（2026-10-20 落地）**：自动清理任务已实现 ——
`apps/api-server/src/modules/track/page-track-cleanup.task.ts`（每日 03:30 Asia/Shanghai，
删除 `created_at` 早于 `now - 180 天` 的行；失败只记日志、不拖垮服务）。
刻意**不进** `TASK_SCHEDULES`、**不受** `TASKS_ENABLED` 影响（保留策略是合规承诺，
不该被业务跑批开关关掉），理由详见该文件头注。单测 `page-track-cleanup.spec.ts`
断言 `PAGE_TRACK_RETENTION_DAYS = 180` 与正文逐字一致。

## 二、微信后台《用户隐私保护指引》表单建议填写值

| 表单项 | 建议填写值 | 说明 |
|---|---|---|
| 收集的信息类型 | **操作日志**（页面访问记录） | 与已声明的「微信授权信息（openid/昵称/头像）」是**两条独立登记**，勿混填 |
| 处理目的 | **运营维护**（保障小程序稳定运行、改进产品体验） | 微信对「操作日志」类的标准目的选项；不选「个性化推荐」 |
| 处理方式 | 收集、存储、使用 | 不出共享、不对外提供 |
| 是否用于个性化推荐 | **否** | 无身份 ⇒ 无个性化；正文亦如此承诺 |
| 信息收集的场景 | 用户使用小程序各页面时（页面打开 / 切换 / 离开） | 端上全局 mixin 自动采集，无需用户操作 |
| 是否收集用户身份 | **否** | openid 仅用于登录态（既有登记），埋点侧不采 |

填写路径：小程序后台 → 设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引。
